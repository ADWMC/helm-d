# 样本接管流程（Intake Playbook）

> 拿到样本后「下一步干什么、计划是什么」的决策树。按需读，非硬性规则。

## 0. 一句话

分诊 → 2-3 步定策略 → 边干边报 → 决策点交回用户。不做长篇空计划。

## 1. 分诊（先动手，不先问）

```bash
file sample.bin                  # 类型 / 架构 / 位数
hash -sha256 sample.bin          # 唯一标识 + 留档
detect_packer sample.bin         # 壳 / 保护器判定
scan_strings sample.bin          # 签名 / URL / 路径 / 报错 / 关键串
```

观察点：

- 熵 > 7.5 → 加壳 / 加密
- 段名 `.vmp` / `.upx` / `.themida` / `.winlice` → 直接定位保护器
- 字符串 `UPX!` / `VMProtect` / `Themida` / `TUSI` → 签名命中
- 无字符串 + 高熵 → 动态优先

## 2. 策略决策（2-3 步内定方向）

| 判定 | 下一步 |
|------|--------|
| 无壳 / 普通 | 静态：imports → xrefs → 关键点 |
| UPX | `upx -d` 或 Frida dump → 静态 |
| VMProtect / Themida | 直接动态：Frida spawn + dump |
| TUSI（定制 UPX） | Frida hook 运行时解壳 / dump |
| 高熵无字符串 | 动态分析，不硬啃静态 |
| 静态 15 分钟无进展 | 切换动态 |

## 3. 每阶段输出

- **事实**：来自工具输出（偏移 / 函数 / 字符串 / 哈希 / dump）
- **推断**：AI 推理，标置信度 高 / 中 / 低 + 依据
- **未知**：缺什么、下一步取什么

## 4. 计划 = 决策点

每个阶段结束给 3-6 个可执行下一步，由用户选方向：

1. 继续静态（imports / xrefs / 关键点）
2. 转动态（Frida / x64dbg）
3. 脱壳 / 反混淆
4. 聚焦特定关键点
5. 报告收尾
6. 停

## 5. 边界

- 单一样本低风险：一路干完，每阶段报证据
- 多文件 / 多阶段 / 高风险：先给简短计划 + 完成标准
- 破坏性操作前确认目标与影响范围；原始样本只读
